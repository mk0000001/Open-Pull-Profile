# 검토와 수정 기록

- 독립 검토에서 공통 출력재2kg 예산이 CAD후보 약5.13kg보다 작다는 문제를 확인했다. 발을4mm 중공 외벽과 기둥 밑 압축 리브로 수정하고, 랩과 커버를 경량화했다. 최종 신규25후보는 CAD질량환산2.709kg이며, 원본 그립/서포트 여유를 포함한 계획 구매량은4kg다. Slicer 검증·출력 적합성 승인을 뜻하지 않는다.
- 형상 없는 원점/기준축을 부품 수에 포함하지 않도록 솔리드만 집계했다. 최종 native부품 수는81/86/91이다.
- 상부 베어링 외륜의 반력 인서트 후보를 추가하고, 이동 패드의 너트 목 부분 간섭 여유를 추가했다. 인서트 끝단 고정, 정확한 저널·체결부 설계는 미완료다.
- 3종 저장 파일의 재개방·STEP왕복·해시검사를 수행했다. 원본과 v0.1/v0.2는 변경하지 않았다. 세 가지 stdlib검사와 manifest검사를 통합했다.
- 추가 공간 검토에서 출력 기둥의 넓은 연결 칼라가 이동판 쪽으로2mm 들어오는 문제를 찾았다. 칼라 폭을88mm로 줄이고 M6볼트 방향을Y로 바꿔 봉/이동부 공간과 분리했다. 지정 이동부와 기둥/칼라를0–100mm11위치에서 검사해 체적 겹침이 없음을 확인했다. 모든 볼트 실장·전부품 동작 간섭의 완료를 뜻하지 않는다.
- 최종 독립 문서/가격/파일 검토에서 추가 중요 지적은 없었다. 이는 완성 기계의 제작 승인이나2kN검증이 아니다. `MODEL_BOM_MAP.json`에서 원본 CAD와 가격 비교품의 불일치도 명시한다.
