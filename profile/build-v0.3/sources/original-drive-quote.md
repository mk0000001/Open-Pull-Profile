## 원본 모터의 제조사 자료와 기계 한계

공식 [전체 데이터시트/치수도](https://files.omc-stepperonline.com/17HS19-1684S-PG14_Full_Datasheet.pdf), [토크 곡선](https://files.omc-stepperonline.com/17HS19-1684S-PG14_Torque_Curve.pdf). 공식 제품 페이지가 직접 연결한 파일이다. STEP는 제품 페이지에서 로그인 다운로드로 제공된다. PDF의 웹 추출은 도형/문자 인식이 제한되어 곡선의 개별 점을 수치로 재작성하지 않았다.

| 제조사 공식 제품페이지 항목 | 값 |
|---|---|
| 감속비 / 입력모터 | 상품명14:1, 사양 **13.73:1** / bipolar1.68A, 기어 제외 홀딩토크0.52N·m |
| 기어박스 | 효율80%, 무부하 백래시≤3°, **max permissible3N·m / momentary5N·m** |
| 크기 | 42×42mm, 모터48 + 감속기35 = 본체83mm |
| 출력축 | **φ8×20mm, D-cut15mm** |
| 출력축 하중 한도 | **축방향50N / 반경방향100N** |

**0.52×13.73×0.8≈5.71N·m를 연속 사용 가능한 출력으로 쓰면 안 된다. 기어박스의 3N·m 한도가 먼저 적용된다.** 순간5N·m 역시 시험기 연속 정격으로 사용할 수 없다. 홀딩토크가 실제 드라이버/속도/온도에서의 운전토크를 보증하지 않는다.

계산상 총2kN 균등분배는 축당1kN이다. 리드2mm, 효율을 임의의 설계 가정0.25로 두면 `T=1000×0.002/(2π×0.25)=1.273N·m/축`이다. 기어 한도3N·m와의 비2.36은 이 가정의 토크 비교일 뿐, 장치 안전율/2kN 보증이 아니다. 1–25mm/min이면 출력0.5–12.5rpm, 입력 약6.87–171.6rpm이다. 실제 저속 곡선과 공급 전류/전압으로 시운전해야 한다.

**1kN 축하중을 50N 허용인 감속모터 출력축에 직접 전달할 수 없다.** 별도 금속 스러스트 하중경로·고정 베어링·축 어깨/너트가 필요하며, 커플링은 토크를 전달하도록 배치해야 한다. 무가공 TR10 나사산을 φ10 정밀 베어링 저널로 간주할 수 없고, 나사산 외경φ10에서 φ10 원통 저널을 선삭해 만들 수 없다. 축단/슬리브/허브 연결은 실제 치수 설계 후 별도 견적이다.

TR10 판매자는 원 제조사 이름·공차도·재료 성적·너트 허용하중·수명/윤활 조건을 공개하지 않는다. 판매페이지의 사진/설명은 리드2 옵션 확인 자료이며, 축당1kN 정격 증거가 아니다. 마찰 자립/전원차단 유지도 자동으로 가정하지 않는다.

2kN 최소성능의 확정에는 실제 조립품으로 하중계 교정, 양축 동기/편하중, 운전토크와 온도, 체결/미끄럼, 축지지/프레임/그립, 파단 및 전원차단 시 거동 검증이 남는다. 현재 결과는 **원본형 저가 부품을 출발점으로 한 견적 조사**다.
