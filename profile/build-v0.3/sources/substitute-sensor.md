## 제조사 근거와 최신 치수

공식 [Zemic Europe H3 제품/견적 페이지](https://www.zemiceurope.com/en/h3), [영문 OEM 데이터시트 2023.01 H3 Rev9](https://www.zemiceurope.com/media/Documentation/H3_Datasheet.pdf), [독문 OEM 2026.02 H3 Rev10-DE](https://www.zemiceurope.com/media/Documentation/H3_Datasheet_DE.pdf)를 확인했다. 공식 사이트는 직접 열기에서403이 발생했으나 검색 인덱스에 제품·견적 방식과 원문 표가 남아 있다. [같은 제조사 Rev9 PDF의 배포 사본](https://vaakatalo.com/wp-content/uploads/2023/04/H3_Datasheet.pdf)을 다운로드하고2/3쪽을 렌더링해 표·도면을 직접 대조했다. 기술값은 판매자 설명이 아닌 이 제조사 작성 문서에서 가져왔다.

| 500 kg 기계 입력 | Rev9 / Rev10-DE 값 |
|---|---:|
| L, 폭 | **50.8 mm** |
| H, 높이 | **76.2 mm** |
| W1, 금속 몸체 두께 | **19.0 mm** |
| W, 커버 포함 두께 | **22.4 mm** |
| H1, 위/아래 하중 프롱 두께 | **14.4 mm, 2곳** |
| M, 위/아래 나사 | **M12×1.75, 2곳** |

나사는 프롱을 지나 바로 열린 S슬릿으로 연결되는 형상이다. 막힌 탭 바닥 깊이를 추정할 필요가 없다. 다만 **14.4 mm 전체가 완전나사 유효길이라는 보증은 아니며 최소 권장 물림 길이는 미공개**다. 스터드 끝이 감지 보나 반대 면에 닿지 않게 해야 한다. H1을 나사 밑으로 남는 고정판 두께나 블라인드 깊이로 잘못 읽으면 안 된다.

구형 Rev4에는 **H1=13.6 / W=20.8**이 있고 미국의 구형 카탈로그에는 L/H 표기 순서와 커버 치수 차이도 있다. 이 옛 값을 새 설계에 혼합하지 않는다. 현재 기구 입력은 위 Rev9/Rev10-DE의 **H1=14.4 / W=22.4**다. 입고품 도면 개정을 주문서에 붙여 맞춰야 한다.

공식 제품 페이지에는 H3 STEP 다운로드가 있으나 이 조사에서는 열거나 수정하지 않았다. 케이블 출구 돌출·정확한 축방향 위치·슬릿 여유는 해당 모델 STEP/공급도면으로 대조할 항목이다. 외형50.8×76.2×22.4만으로 모든 출구 형상을 확정한 것은 아니다.

## 하중·안전 수치·교정의 의미

제조사 데이터시트의 C3 사양:

- 출력2.0±0.004 mV/V, 종합오차≤±0.020% FS, 크리프≤±0.016% FS/30분.
- 안전 과부하150% FS≈**7355 N**, 파괴 과부하300% FS≈**14710 N**. 정상 사용 목표는 정격 내로 둔다.
- 니켈 도금 합금강, IP67, 보상온도−10..40°C, 동작온도−35..65°C.
- 입력350±3.5 Ω / 출력351±2 Ω, 영점≤±1.5% FS.
- M12 고정 체결 토크 표기75 N·m. 이 토크로 출력물을 직접 조여도 된다는 뜻은 아니다. 센서 금속부/잠금너트와 출력 지지부의 하중 분산을 구분해야 한다.

약0.981 N의0.020% FS 종합오차는 센서 항목이다. 완성 시험기의 전체 힘 불확도·피크 오차가0.981 N이라는 뜻은 아니다. 동하중 피로 횟수나 기계 안전기능용 SIL/PL 등급은 확인하지 못했다. IP67과 OIML C3도 파손 위험을 판단하는 구조 안전등급은 아니다.

[PTB H3 인장 로드셀 형식시험서](https://www.zemiceurope.com/media/Documentation/H3_OIML_TC.pdf)는 H3,100–2500 kg,C3/C4를 대상으로 한다. 이는 개별 센서의 인장 교정 성적서와 다르다. [제조사 FAQ](https://www.zemiceurope.com/de/faq/force-sensors---load)는 **모든 Zemic Europe 로드셀에 생산 중 측정값이 담긴 고유 교정서를 제공한다**고 명시한다. [제조사 교정 설명](https://www.zemiceurope.com/de/blogs/loadcell-calibration)에서도 개별 교정서 제공을 확인했다. 구체적으로 구매할 센서의 시리얼·인장방향 결과·추적성 범위가 필요한 경우는 견적 조건으로 분리한다. 기본 공장 교정서를 KOLAS/ISO17025 인장 교정으로 바꿔 부르지 않는다.

## HX711와 그립 연결

센서 권장 여기전압은 **5–12 V**, 최대18 V다. 원본 HX711를 유지하되 **브리지 E+/E−와 HX711 아날로그 기준이 같은 약5 V인 비율식 구성**으로 잡는다. 일반 저가 HX711 모듈의 E+가 약4.3 V인 경우가 있으므로 전원 입력5 V만 보고 센서 여기5 V라고 쓰면 안 된다.4.3 V 사용이 제조사 권장 범위 안이라고도 쓰지 않는다. 칩의 외부 아날로그5 V 공급 구성/모듈 회로를 전기 담당이 확인해야 한다. 센서에12 V를 여기하고 HX711 입력에 임의 연결하는 구성이 아니다.

배선: **빨강 E+ / 검정 E− / 초록 A+ / 흰색 A−**. 원본 TC4의 흰색SIG+/노랑SIG−와 다르다.4선 케이블 길이를 바꾸면 개별 교정계수가 달라질 수 있으므로 장착 후 전체 계측계를 다시 교정한다.10/80 SPS는 모듈 RATE 연결을 확인한다.

기계 하중은 상부 프롱 나사→센서 감지부→하부 프롱 나사로 전달한다. 센서 커버나 측면을 출력 그립으로 물려 하중을 걸지 않는다. M12 금속 로드엔드/아이볼트와 강재 핀·부싱을 써서 출력 클레비스/그립으로 연결할 수 있으나, 원본 Ø17×22 cavity와 자동으로 호환되는 부품은 아니다. 출력 그립의 형상을 센서 사양의 증거로 사용하지 않는다.

OEM 장착 부속으로 [HL-3-001-500/750kg-LM,2030035](https://www.zemiceurope.com/media/Documentation/HL_3_001_Datasheet.pdf)는 H3와 호환되고 부속 자체 정적 인양0.8 t를 표기한다. [HL-3-005-500/750kg M12,20303560](https://www.zemiceurope.com/media/Documentation/HL-3-005_Datasheet.pdf)도 H3용 아이볼트+포크 조립체이며 부속 자체0.8 t 표기가 있다. 이 부속의 정격을 센서·출력 그립까지 포함한2 kN 완성 지그 보증으로 사용하지 않는다. 부속 가격과 체결 물림/너트 배치는 견적 미확정이며 임의로 완성 BOM에 넣지 않는다.
