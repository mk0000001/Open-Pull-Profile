# 원본 AEP TC4 5 kN 센서: 인터페이스와 예산

조사일 2026-10-24. 원본 센서 유지안이며 다른 센서를 혼합하지 않는다. 구매·문의 발송·CAD·Git 작업 없음. 앞선 500 N SC134 예산안은 중지한다.

## 결론

원본 [CNC Kitchen Open-Pull README](https://github.com/CNCKitchen/Open-Pull/blob/master/README.md)의 센서는 **AEP TC4 5 kN + HX711**이다. 로컬 README 33/36행에서도 확인했다. 정확한 kN 교정 제품 식별자는 **CTC41005KNI15**이며, kg 교정 형제 품번 CTC4100500K5와 주문 시 구분한다. TC4-AMP, DC-TC4, microTC4는 이 센서와 다른 제품이다.

5 kN 센서 자체는 2 kN 목표의 2.5배 정격이지만, 원본 그립/출력 고정부/프레임의 2 kN 보증으로 확대할 수 없다. 실물 조립체 시험과 인장 방향 계측 교정 없이 “최소 2 kN 보장”을 확정하지 않는다.

**공개 해외 단품가는 €635, 약 94.1만 원 세전 환산이다.** 국내 취급처는 견적 전용이다. 공식 인장 부속까지 포함한 공개 해외 참고 합계는 **€1,004, 약 148.8만 원 세전**, 단순 10% 가산 비교액은 약 **163.7만 원**이다. 운송·수입 제비용·국내 유통마진·인장 교정·전체 구조 시험은 별도다. 따라서 센서를 새로 사는 원본 유지안은 센서만으로 50만 원 총예산을 넘는다. 이 금액은 국내 확정 견적이나 최저가가 아니다.

## 제조사 도면으로 확정한 기계 입력

[AEP TC4 제조사 데이터시트 TC4.R13](https://www.aep.it/wp-content/uploads/2020/02/Data-sheet-TC4.pdf), 4쪽을 직접 다운로드하고 1–4쪽을 렌더링해 확인했다. 파일 메타데이터 생성일은 2025-10-29다.

| 5 kN 입력 | OEM 값 / 해석 |
|---|---|
| 몸체 외경 A / 두께 C | **Ø100 / 35 mm** |
| 중앙 하중 나사 F | **M20×1.5**, 단면에서 몸체 양면으로 개방된 **관통나사** |
| 나사 깊이의 의미 | 막힌 구멍의 바닥 깊이는 없다. 몸체 축방향 두께는 35 mm이나, 양단 모따기·불완전산을 제외한 완전나사 유효길이와 최소 권장 물림은 별도 미공개. **35 mm 전부를 보증 물림으로 취급하지 않는다** |
| 외측 고정구멍 | **6×Ø9 관통**, PCD **86 mm** |
| 기타 동심 치수 | ØD **72**, ØE **32** |
| 연결부 포함 외형 H / T | **121 / 7.5 mm**. H는 도면의 연결부 포함 전체 방향 치수이며 센서 축방향 높이가 아님 |
| 축방향 연결부 폭 | 도면 고정값 20 mm. 출구 세부 외형은 1쪽 도면 / OEM STEP 참조 |
| 케이블 연결부 | 도면에 G1/4 표기. 이는 중앙 하중 연결나사가 아님 |
| 고정볼트 | **M8, 강도 12.9, 체결토크 40 N·m** (2쪽) |
| 질량 / 정격 처짐 | 약 **1.6 kg / 0.06 mm** |

범용 정면 그림에는 8개 구멍이 그려져 있지만 **5 kN 표의 n°G는 6개**다. 5 kN의 각도 기준과 케이블에 대한 홀 위상은 정확한 OEM 모델 또는 실물로 확인한다. 원본 STEP의 약 Ø17 구멍만으로 나사 규격·피치를 역추정하지 않는다.

정식 제조사 STEP은 [TC4 제품 페이지](https://www.aep.it/en/product/force-transducers/tc4/)의 실제 링크로 확인했다. 이 조사에서는 열거나 수정하지 않았다.

- [TC4 Ø100 단품 STEP](https://www.aep.it/wp-content/uploads/2020/02/TC4-100.stp)
- [TC4 Ø100 인장 부속 조립 STEP](https://www.aep.it/wp-content/uploads/2020/02/TC4-100-with-tension-accessories.stp)

원본 계보를 보존하면서 센서 전용 마운트만 이 자료와 대조하면 된다. 위 6×M8 체결토크는 출력 PETG를 40 N·m로 직접 조여도 된다는 뜻이 아니다. 제조사의 교정 조건은 지지체에 올바르게 체결된 센서다. 금속 OEM 베이스/스페이서 등 실제 체결 구조가 필요하며 출력 부품의 압축·크리프는 별도 검증 대상이다.

## OEM 인장 연결 구조

제조사 R13 3쪽은 **CPBTC4D100 베이스 + CACCEM20 로드엔드 2개**로 인장 사용을 보인다. 센서 중앙과 베이스 중앙은 서로 다른 하중 부재다. 센서 중앙 관통나사 양쪽에 로드엔드만 달아 서로 당기면 센서 외측 링과의 하중차가 성립하지 않을 수 있으므로 OEM 조립도를 따라야 한다.

OEM 인장 조립 외형: 센서35 + 베이스37 = 축방향 몸체72 mm, 표의 핀 중심 간 길이 M은 약 **170 mm**. 정확한 삽입 길이는 이 근삿값에서 역산하지 않는다.

[AEP ACCEM.552.R7 도면](https://www.aep.it/wp-content/uploads/2020/02/ACCEM-4.pdf)의 CACCEM20:

| 항목 | 치수 mm |
|---|---:|
| 나사 | M20×1.5 |
| 핀 구멍 C | 20 |
| 볼 폭 A / 하우징 폭 B | 16 / 13 |
| 볼 관련 지름 D | 24.1 |
| 핀 중심→나사 끝 E | 78 |
| 나사 길이 G | 43 |
| 헤드 외경 I | 53 |
| 잠금너트 두께 L / 대변 Ch | 9 / 30 |

핀·클레비스는 Ø20 핀과 볼 폭16에 맞춰 별도 선정해야 한다. 구멍이 크다고 기존 출력 그립의 Ø17×22 공간에 억지로 맞출 수 없다. 출력 그립의 기하·재질·체결부는 새 인터페이스에 맞춰 설계하고 실물 시험한다. OEM 자료는 로드엔드의 스틸/스틸 조합과 ISO12240-4 Series E 치수를 명시한다. 2 kN 완성 그립 정격은 제공하지 않는다.

## 2 kN 목표와 HX711 유지

OEM 정격5 kN에서 2 kN은40% FS. 최대 동하중 표기75%=3.75 kN이므로 센서 부품에는2 kN보다 여유가 있다. 단 동하중은 중앙 나사로 가해야 한다는 OEM 주석이 있다. 과부하 수치는 사용 목표로 삼지 않는다.

전기사양은 표준2 mV/V, 권장10 V, 허용 여기1–15 V, 입력800±20 Ω, 출력705±2 Ω다. HX711의 약4.3–5 V 브리지 여기전압도 센서 허용범위에 들어간다. **HX711 입력에10 V를 직접 공급한다는 뜻이 아니다.** 비율식으로 HX711의 기준 전원과 같은 전원에서 브리지를 여기한다. 5 V에서 정격10 mV,2 kN 약4 mV 예상이다.

TC4 배선은 **빨강 EXC+ / 검정 EXC− / 흰색 SIG+ / 노랑 SIG−**다. SC134/TAS 계열의 초록/흰색 결선과 혼합하지 않는다. 실드는 센서 몸체에 연결되어 있다. HX711 채널 A에 흰색 A+, 노랑 A−를 쓴다. 입고 모듈의 RATE 구성과 실제10/80 SPS는 확인해야 한다.

OEM 기본 시험·교정은 올바르게 지지/체결한 **압축 방향**이다. 사용자는 인장시험을 하므로 인장 교정 보고서 또는 추적 가능한 인장 비교교정을 별도 비용 항목으로 둔다. ISO376 Class1과 센서의 선형성0.05% FS를 완성 시험기의 총 오차로 주장하지 않는다.

“최소2 kN 보장”을 가격만으로 확정할 수는 없다. 현재 원본 센서 경로의 비용 기준은 **센서 단품 약94만 원 세전, OEM 인장 연결 포함 약149만 원 세전**, 국내 견적·교정·조립체 시험 별도다. 이 기준과 전체 구조 BOM을 합쳐 예산을 판단한다.
