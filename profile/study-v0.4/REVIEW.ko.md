# 검토·검증 기록

2026-10-25. 독립 검토자는 견적 합산과2kN/ISO/축소 시편 범위 표기를 확인했다. 중요한 발견은 원형의 좌우 죠가 대칭이라 우측003/004의 이동 방향을 반대로 적용해야 한다는 점이었다. 수정 후 재생성했으며,검사 JSON의 양쪽2mm 간격과 저장 네이티브 BREP/XML에서 약y19.000238/21.000238을 독립 확인했다. 나사/손잡이 전체 재체결은 여전히 미완료다.

별도 headless FreeCAD로 네이티브3개를 다시 열어 유효 솔리드와 STEP 체적 차이를 확인했다. 정밀한 원형 스플라인이 포함된 UTM은 상대1e-5,자체 재구성 두 모델은1e-8을 적용했고 실측 차이는 EXCHANGE_CHECK.json에 보존했다. 이는 수치적 교환 확인이며 하중 검증이 아니다. 테스트가 정격2kN나ISO 적합성을 참으로 바꾸지 않는다.

일반 Python의 예산·교환 해시 테스트3개 및 기존 v0.3 검사3개,릴리스 버전/파일 해시/상위 원본 보존 검사를 통과했다. 전체 unittest 자동 검색은 FreeCAD 전용 두 기존 모듈을 일반 Python으로 가져오려다 실패했으므로 해당 명령을 전체 테스트 통과로 기록하지 않는다. 네이티브 기하 검사는 FreeCAD에서 별도로 수행했다.

추가 진단에서 STEP의 각 솔리드 중심을 중첩 반복으로 계산해 GUI 작업이 시간 초과됐다. 파일은 이미 저장돼 있었고,교환 재검증은 GUI와 독립인 headless 프로세스에서 성공했다. 저장 네이티브9개를 작업 외부 artifacts/v04-freecad-recovery에 백업하고 해당 FreeCAD 인스턴스만 다시 열었다. 다른 FreeCAD 인스턴스와 원본/이전 버전 파일은 수정하지 않았다.

미완료: 실제 구매 옵션/배송/가공 확정,대체 모터·센서 장착,전체 반력·연결부·전장/차폐,교정·2kN 단계/반복하중,ISO 적합성. 이 릴리스는 타당성 검토이며 제작 승인판이 아니다.
