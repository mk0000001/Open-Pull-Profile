# v0.2 검토 기록

별도 읽기 전용 검토와 FreeCAD 재검사를 수행했다. 구매·판매자 연락·기계 작동은 하지 않았다.

| 발견 | 처리 | 검사 범위 |
|---|---|---|
| 가이드 높이 수정 후 이동판 전면과 상/하판4mm 겹침 | 상/하판 앞변Y−72→−68 트림 | 대응 부품 common volume=0 |
| FF M4×16 볼트가 하부 보에1mm 진입 | M4×12로 변경, 판 물림9mm | 모든 FF 볼트와 하부 두 보의 체적 교집합=0 |
| 모터 브리지 웹과 지붕 겹침 | 웹 바닥을 지붕 상면Z992에 배치 | 웹–지붕 및 웹–모터판 체적 교집합=0 |
| 기존 창의 오래된 CAD가 검사에 재사용될 가능성 | 같은 경로의 열려 있는 v0.2 문서를 닫고 디스크에서 재열기 | 새 속성 MotorWrapDegrees를 포함한116부품 검사 |
| 벨트 이물림 약4.03개/모터 감김각72.50° | 제조사 정격 보정 또는 아이들러 재설계 보류 | 피치 경로 계산값만 검증, 전달 용량 합격 아님 |
| v0.1만 확인하던 해시/버전 검사 | 최신 v0.2와 보존 v0.1을 각각 묶어 확인 | 두 CAD 컨테이너·버전·상태·시험 파일을 포함한 해시 검사 |

첫 테스트는 모델 파일이 없어 의도대로 실패했다. 최종 결과는 VALIDATION.json/ROUNDTRIP.json에 저장했다. 형상 검사 성공은 전체 부품의 체결 완료·가공도 완성·하중 인증과 다르다. 공급자 실재고/최종 견적, 프레임 일괄 체결, 센서 어댑터, 벨트/축 전달과 FK 축하중, 낙하 방지·전장 검증은 여전히 필요하다.
