## 제조사 자료와 대조해 발견한 구체적인 차이

### 1. 모터 축과 본체 길이

현재 CAD/BOM 가정은57×57×112mm, 축8mm, 모터 풀리 보어8mm다. 비교한 제조사 [STEPPERONLINE 23HS45-4204S](https://www.omc-stepperonline.com/nema-23-bipolar-3nm-425oz-in-4-2a-57x57x114mm-4-wires-stepper-motor-cnc-23hs45-4204s)는3Nm·4.2A, 본체113mm, **축10mm**, 축길이24mm다. 이 제품을 그대로 사면 현재8mm 풀리가 맞지 않는다.

이 제조사 페이지는 치수 비교 근거다. 사용자가 지정한 알리/국내 구매 경로에서 동일 모델/도면을 확인한 판매 링크를 확보한 상태는 아니다. 실제 구매 모터를 먼저 고르고, 모터/풀리/브라켓/전류 설정을 함께 수정해야 한다. NEMA23이라는 플랜지 규격만으로 축 지름이나 모터 전류가 정해지지 않는다.

### 2. 가이드 장착면 높이

현재 모델은 레일 설치면 Y=-40, 블록의 크로스헤드 장착면 Y=-72로32mm를 가정했다. [HIWIN HG 제조사 도면](https://www.hiwin.com/wp-content/uploads/HG-Info.pdf)의 HGH15CA는 조립 높이 H=28mm, 폭34mm, 전체길이61.4mm다. 실제 HIWIN 부품을 쓰면 현재 가정과 높이가4mm 다르다. 크로스헤드 위치를 바꾸거나 적합한 스페이서를 설계해야 한다. 모델 블록 길이60mm도 실제 치수로 바꿔야 한다.

알리의 유사품에 HIWIN 정품 정격이나 치수를 자동으로 적용하지 않는다. 구매할 판매자의 도면을 기준으로 레일·블록·장착 구멍을 같이 확정한다.

### 3. 볼스크류 길이/가공단/지지대

현재 모델은900mm 길이의 지름16mm 원통으로 나사 위치를 표현했다. 실제 축 끝단은 그렇지 않다. [DOLD SFU1605 제조사/판매자 도면](https://www.dold-mechatronik.de/documents/Datenblaetter/Kugelumlaufspindeln/Datenblatt-Kugelumlaufspindel-einbaufertig.pdf)은 SFU1605-3와SFU1605-DM의 서로 다른 가공단을 보여준다. 예를 들어 -3 계열의 호칭800mm는 총길이865mm로 제시된다. ‘900mm’라고만 주문해서는 설치 간격이 보장되지 않는다.

BK12 계열에는12mm 베어링 시트·고정 너트 등의 실제 가공이 필요하다. 현재 CAD의 단순 지지대 블록/관통 구멍은 실제 BK12의 설치 형상으로 검증되지 않았다. [THK 지지대 형상](https://www.thk.com/us/en/products/ball_screw/support_unit/ek_bk_fk/)처럼 블록형 BK/BF와 플랜지형 FK/FF는 체결 방식이 다르다. 수직 축의 상부 판 체결에는 실제 방향에 맞는 브라켓을 설계하거나 FK/FF 계열로 다시 선정하는 편이 검토하기 쉽다. 정격 축하중은 구매할 제조사의 베어링/너트 데이터로 확인한다.

### 4. 로드셀·그립 연결

[CAS SBA 공식 자료](https://www.cas.co.kr/integration/read.jsp?code=20200813f2610ff062&no=115&reqPageNo=1)는200kgf~1tf 계열의 로드 엔드 액세서리 나사를 M12×1.75로 제시한다. [카스몰 SBA](https://cas-mall.com/goods/goods_view.php?goodsNo=1000000249)에서 **SBA-500L 옵션을 실제 선택해1개198,000원**을 확인했다. 장바구니 추가나 주문은 하지 않았다.

이로써 국내500kgf 센서의 구매 후보와 나사 계열은 구체화됐다. 그러나 현재 CAD의 S형 센서50×25×66mm는 특정 SBA-500L 실외형으로 검증되지 않았다. 로드 엔드 두 개와 핀/전환 어댑터의 공간을 포함해 다시 배치해야 한다. 원본 출력 그립을2kN 정격으로 취급하지 않는다.

## 직접 확인한 국내 구매 옵션

- [영진4080](https://www.yjprofile.co.kr/goods/goods_view.php?goodsNo=1000000051): 경희프로파일/경희알미늄, 국내 제조 표기.801~900mm 구간을 실제 선택하면 **28,710원/개**.401~500mm 구간은 기본80원+옵션15,870원으로 **15,950원/개** 계산. 세부 길이/수량을 별도 필수 입력하는 주문 방식이다.900×2와420×4의4080 소계는 **121,220원**이며,4040·배송·탭/홀 가공·브라켓은 별도다. 표시 재고는 공급 가능성 참고이며 판매자의 주문 수락을 확인한 것은 아니다.
- [카스몰 SBA-500L](https://cas-mall.com/goods/goods_view.php?goodsNo=1000000249):500L 옵션 선택198,000원, 화면상 배송0원. 이 가격은 센서1개이며 로드 엔드·핀/어댑터 포함으로 간주하지 않는다.
- 쿠팡 HX711·S형 센서·DM542 등은 후보가 있으나, 과거 배송일/색인 자료 또는 접근 제한 때문에 최신 옵션·재고를 확정하지 못했다. 소싱 표의 상태를 유지한다.
- 알리 볼스크류·레일은 아직 검색/탐색 후보다. **정확한 옵션과 끝단 도면을 검증한 구매 확정 링크가 아니다.**

따라서 이번에 직접 확인한4080+국내 센서 소계만 **319,220원**이다. 종전의 프로파일5~9만원 추산은 이 판매처 기준으로 낮았으므로 수정했다. 국내 센서 기준 전체 예산 틀은 대략 **91만~155만원**, 금속 그립 제작·전문 교정·일부 공구/배송은 별도다. 확정 견적이 아니며, 가공도와 낙하 방지안을 고르면 달라진다.

## v0.2에서 구매 가능 상태로 바꾸는 순서

1. 같은 판매자 도면을 갖춘 두 축의 정확한 나사·지지대·너트 하우징 세트, 두 레일/네 블록 세트를 선택한다. 총길이·유효 나사 길이·양 끝 시트/너트 규격을 명시한다.
2. 국내/알리의 실제 판매 모터 모델과 드라이버를 고정하고, 축 지름에 맞는20T 풀리와40T 풀리 두 개를 선택한다. 벨트의 치형·실제폭·텐셔너 범위를 확정한다.
3. 로드셀/로드 엔드 실치수와 그립 연결부를 넣고 지지대 브라켓/판재의 모든 홀·탭·공차를 완성한다. 체결 볼트 수량과 도구 접근성까지 확인한다.
4. 프로파일 실단면, 상부 보/받침판, 하부 연결판, 볼트·핀, 베어링과 그립의 하중 검토를 수행한다. 낙하 포획 장치를 도면에 넣는다.
5. 그 가공도로 국내 가공비를 받은 뒤 구매한다. 무부하 이동, 정렬·역구동 방지, 단계별 교정과 반복 실험을 거쳐 작동 하중 한계를 정한다.

실제로 기계를 제작·가동하거나 센서 하중 시험을 실행하지 않았다. 이번 검증은 문서·제조사 자료·판매 옵션·디지털 CAD를 대상으로 한다. **제작 승인, 안전 인증, 측정 정확도 보증을 뜻하지 않는다.**
