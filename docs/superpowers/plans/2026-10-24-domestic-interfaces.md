# v0.2 국내 판매품 도면 대조

사용자 지시: 국내 판매 기준, 미스미와 쿠팡 저가품 비교. v0.1 태그는 수정하지 않는다.

- [x] 국내 판매 URL/정확한 옵션/가격 상태와 제조사 도면 조사.
- [x] 모터·나사·지지대·가이드·그립의 v0.1 가정을 실제 도면과 대조.
- [x] 도면 인터페이스 검사 실패 확인 후 별도 v0.2 FreeCAD 생성기 작성.
- [x] 실제 장착 구멍, 나사 끝단, 지지대, 가이드, 체결 볼트를 배치하고 검사.
- [x] 가격 비교표와 미확정 체결부를 함께 저장하고 별도 검토.
- [ ] 재열기·STEP 교환·해시 검증 후 fork 브랜치 게시, 원격 SHA/파일 대조.

이번 CAD의 정확한 범위는 구매품 도면에서 재구성한 외형/체결부와 기존 개념 프레임의 조립 검토다. 모터 내부·나사 헬릭스·구름요소·벨트 치형은 생략한다. 센서와 원본 그립의 연결은 미확정이므로 기존 M8 연결봉을 삭제하고 열려 있는 하중 경로를 명시한다. 전 부품이 완전히 체결되거나 실물 조립 가능한 완성품이라고 표시하지 않는다. 이 상태에서 가공·발주·가동을 승인하지 않는다.

실행 기록: 최초 검사에서 v0.2 모델 미생성 실패를 확인했다. 재생성 후 디스크에서 강제 재열어116개 형상과11개 이동 위치를 확인했다. 별도 검토에서 이동판 접합4mm 겹침·FF 볼트1mm 돌출·모터 벨트 감김각72.50°를 발견했다. 앞의 두 형상은 수정하고 회귀 검사, 벨트는 정격/아이들러 재설계 보류로 기록했다. v0.1 CAD/STEP/렌더/설정은 태그와 바이트 대조한다. 원격 게시 완료는 다음 기록에서 커밋 SHA로 확인한다.
