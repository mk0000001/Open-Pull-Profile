# Open-Pull Profile — v0.1.0-design

작성일: 2026-10-24 (Asia/Seoul). 상태: **구매·제작 전 검토용 설계**, 실물 미검증.

## 목적과 근거

출력한 플라스틱 인장 시편으로 소재·출력 조건을 비교한다. 사용자가 CNC Kitchen Open-Pull을 기반으로 프로파일 프레임으로 재설계하고, FreeCAD에 올리고, 알리·국내 판매처(가능하면 쿠팡)를 조사하고, 실제 GitHub 포크로 게시하며 버전 이력을 관리하도록 요청했다. 기존 대화 조회에서는 답변 본문이 제공되지 않아 그 대화의 수치나 부품을 확정 요구사항으로 쓰지 않았다.

원본: https://github.com/CNCKitchen/Open-Pull , 기준 커밋 `55017419fae89409b1098540212e1620b1e46d0b`, GPL-3.0. 원본 CAD·Arduino·문서는 수정하지 않는다. 원본은 감속 NEMA17 두 개, TR10×2 나사 두 개, HX711, 광학 신율 측정을 사용한다. 원본 STEP의 그립 형상을 새 모델에 복사해 계보를 명시한다.

## 검토한 접근과 이번 판단

1. 4040 프레임·단일 나사: 저렴하지만 이동부 비틀림과 편심이 커져 이번 안에서 제외.
2. 4080 두 기둥·두 나사 동기 구동: 추천안. 원본의 두 나사/교체식 그립/로드셀 측정 방식을 계승하고, SFU1605와 레일을 이용해 국내·알리 조달성을 높인다.
3. 5kN급 장비: 프레임뿐 아니라 베어링, 그립, 축 연결, 접합부의 정격과 실증을 다시 선정해야 하므로 별도 설계 단계로 둔다.

사용자는 프로파일과 원본의 혼합 재설계를 진행하도록 지시했다. 세부 치수, SFU1605, 단일 모터 벨트 동기화는 작성자의 제안이며 사용자가 정한 사양으로 표현하지 않는다.

## 목표와 한계

- 연구 목표 하중: 2,000N. **허용하중/정격/검증된 작동 한계가 아니다.** 초기 시운전은 무부하부터 시작하고 하중 한계는 실제 부품 정격과 실물 검증 뒤 설정한다.
- 로드셀 후보: 인장용 S형 500kgf(약 4,903N). 센서 용량은 장비 허용하중을 뜻하지 않는다.
- 5×2mm 단면에서 60MPa라면 약 600N, 10×4mm에서는 약 2,400N이다. 작은 비교 시편부터 시작한다. 이 수치는 설계용 예시이며 소재의 보증 강도가 아니다.
- 초기 비교 속도 목표: 1/5/25mm/min. 표준 인증이나 ISO/ASTM 준수 시험을 주장하지 않는다.
- 초기 배치에서 인장 방향 이동 목표 100mm. 긴 연성 시편/TPU 대변형에는 추가 높이와 이동 범위 검토가 필요하다.
- 크로스헤드 이동량은 시편 신율이 아니다. 탄성률은 표점 추적/별도 신율계가 필요하다.

## CAD 배치 (mm)

좌표: X 좌우, Y 앞뒤(앞쪽 음수), Z 높이. 시험 축 X=0,Y=0. 단위 mm.

- 기둥: 4080 × 900, 2개. 단면 X40×Y80, 중심 X=±230, Z=80…980.
- 상·하부 가로보: 4080 × 420, 4개. 각 위치에 앞뒤 2개를 배치해 깊이 80, 높이 80을 만든다. Z=80…160 / 900…980.
- 발: 4040 × 400, 2개. 발 기준 폭500×깊이400, 차폐 포함 전체 외형 약510×415×1067.
- 뒤쪽 접합판: 상부500×160×8, 하부500×80×8 각1개. 상부 베어링 받침판500×120×12. 고정 그립 받침판420×100×12.
- 큰 판재는 AL6061-T6를 조달 후보로 두고, 그립 어댑터·핀은 강재 후보로 둔다. 재질별 강도·강성 검토 전 두께를 확정하지 않는다.
- 두 SFU1605, 호칭 길이 900 후보, X=±160,Y=0. **총길이/나사부 길이/가공단 치수는 판매자 도면 확인 전 확정 아님.** 상부 고정 BK12, 하부 부동 BF12 배치. 보와 판에 축 관통용 가공이 필요하다.
- 레일: HGR15 700, 2개 + HGH15CA 블록 4개. 기둥 전면에 설치. 모형은 장착 공간만 표현하며 실제 홀 피치는 판매자 도면에 종속된다.
- 이동 크로스헤드: 앞 연결판 500×160×12, 상·하판 400×122×12, 뒤 보강판 400×136×12. 나사와 시험 축의 Y 좌표를 맞춘다.
- 그립: 원본 STEP에서 상·하 그립 전체 형상을 가져오고, 금속 어댑터/핀 연결 후보를 추가한다. **원본 출력 그립의 2kN 내하중은 입증되지 않았다.** 물림·파손 시험 뒤 금속 본체/상용 그립으로 교체할 수 있다.
- 구동: NEMA23 약 2~3Nm 1개, 모터 20T/나사 각 40T, HTD5M 15mm 벨트. 모터 슬롯과 텐셔너를 설계에 남긴다. 벨트는 축의 좌우 동기화용이며 하중을 지지하지 않는다.
- 센서: S형 외형 공간, M12 축 연결 제안. **500kg 옵션의 실제 나사와 외형 확인 후 어댑터를 확정한다.** 원본 그립 연결부 규격과 다르면 금속 전환 어댑터가 필요하다.
- 전면·측면 폴리카보네이트 차폐와 구동부 커버 공간 표시. 두께 4mm는 배치 가정이며 파편 차폐 성능의 보증이 아니다.

프로파일 단면과 구매품은 단순화한 외형이다. 판매자별 홈 폭/단면 2차모멘트/베어링/레일 도면을 얻기 전 가공 도면으로 사용하지 않는다. CAD의 평행판·핀은 연결 방식을 검토하는 형상이며 모든 나사 체결·공차·끼워맞춤을 완성한 상태는 아니다.

기하 검증에서 최초 800mm 기둥 배치는 100mm 인장 이동 시 크로스헤드 하판이 하부 보와 간섭했다. 이를 해결하기 위해 기둥·나사 길이를 각100mm 늘리고 시험부와 상부 구동부를 100mm 올렸다. 레일 길이700mm는 유지하고 시작 높이를200mm로 올렸다. 최종 그립 외형: 하부 Z500…580, 상부 Z681…761. 이 변경은 작성자의 검증 기반 판단이다.

독립 검토에서 하부 뒤 접합판이 초기 검사 대상에서 빠진 것을 발견했다. 100mm 하강 시 하판/뒤 보강판과의 간섭을 재현하고, 접합판·받침판·레일·가이드 블록까지 검사 대상을 확장했다. 하부 접합판 높이를80mm(상단Z160)로 줄여 이동 경로를 확보했다. 하부 체결부의 강도는 여전히 제작 전 검토 대상이다.

## 하중과 제어 검토

2kN, 리드5mm, 나사 효율0.9 가정 시 두 나사 합계 요구 토크는 F·L/(2π·η)=약1.77Nm. 2:1 감속에서 벨트 손실을 무시한 모터 토크는 약0.884Nm. 실제 모터 선정은 저속 토크, 가속, 벨트 손실, 편하중과 여유를 포함한다. 상부 고정 베어링에서 축 하중을 받도록 설계하고 커플러·모터 베어링으로 축 하중을 받지 않는다. 중앙 고정 그립과 두 상부 나사 베어링이 상부 가로보에 반대 방향 하중을 주므로 상부 보·판·연결부의 굽힘 검토가 핵심이다.

볼스크류는 역구동할 수 있다. 전원 차단 시 이동부 낙하를 막는 기계식 포획장치/브레이크/균형추를 확정하기 전 동력 시운전하지 않는다. NC 리미트 2개, 비상정지, 드라이버 전원 차단과 별도 낙하 방지, 접지·퓨즈·전장함이 필요하다. 비상정지로 유지 토크를 끊는 것만으로 안전이 확보되지 않는다.

원본 펌웨어는 보존용이며 새 구동계용으로 검증되지 않았다. 200step/rev, 8마이크로스텝, 2:1 감속, 5mm 리드라면 640step/mm이나 실제 스위치/드라이버/전송 방식으로 재확인한다. 원본의 약14:1·2mm 리드 설정을 그대로 사용하면 속도와 이동량이 틀린다. 로드셀 영점·감도·부호·단위도 재교정한다. 이번 버전은 새 펌웨어를 작성하거나 기계를 작동시키지 않는다.

## 산출물과 검증

원본 STEP를 FreeCAD 참조 문서로 연다. 재설계 FCStd/STEP, 재생성 매크로와 설정 JSON, 정면·사시도, 부품표 CSV, 절단 목록, 구매 후보 링크·가격 근거·미확정 항목, 변경 기록과 검증 JSON을 버전 관리한다. 검증은 CAD 유효성, 프레임/이동부 간섭, 시편·그립 중심, 100mm 인장 이동 여유, 원본 보존, 파일 해시와 원격 브랜치/태그 일치를 확인한다. 기하 검증은 구조강도 검증이 아니다.

## 다음 제작 단계에 남기는 결정

판매자 도면으로 축 끝단·너트 하우징·베어링 정격·레일 구멍·센서 나사를 고정한다. 모든 하중부 체결/핀/접합부를 치수화하고, 가공 견적 및 실물 계측을 반영한 v0.2를 만든다. 접합부/그립/낙하 방지 검증, 하중·변위 교정, 시험 반복성 확인 뒤 제작 가능 상태를 판단한다. 예산과 재고를 확정하기 전 구매하지 않는다.
